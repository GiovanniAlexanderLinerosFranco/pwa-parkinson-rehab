# Internacionalización (i18n)

Patrón alineado con TrainAIfit.health (`next-intl`).

## Cómo funciona

- Rutas con prefijo de idioma: `/es/...`, `/en/...`
- Mensajes: `messages/es.json`, `messages/en.json`
- Config: `src/i18n/routing.ts`, `src/i18n/request.ts`, `src/i18n/navigation.ts`
- Proxy Next.js 16: `src/proxy.ts` (redirige `/` → `/es`)

## Uso en componentes

```tsx
import { useTranslations } from 'next-intl';
import { Link } from '@/i18n/navigation';

const t = useTranslations();
t('cueing.title');
<Link href="/ejemplos-sesion-clinica">...</Link>
```

## Añadir un idioma (fase 2)

1. Crear `messages/pt.json` (copiar desde `es.json` y traducir).
2. Añadir `'pt'` en `src/i18n/routing.ts` → `locales`.
3. Actualizar el matcher de `src/proxy.ts` si hace falta.
